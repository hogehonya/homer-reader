# IBM Plex Sans JP

IBM公式の`@ibm/plex-sans-jp` 3.0.0から、Regular 400とBold 700の未改変WOFF2を配置しています。上流は[IBM/plex](https://github.com/IBM/plex)、再配布条件は同梱の[SIL Open Font License 1.1](LICENSE.txt)です。

フォントは`src/styles.css`から自己ホストし、`font-display: swap`と日本語システム書体のfallbackを使います。
